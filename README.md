# 紅色風暴 Red Storm — Unreal Engine 5.4 版

《紅色風暴》的 3D 重製版（UE 5.4 C++）。所有模型、地表貼圖、介面都由程式產生，全部原創。

網頁遊玩版（Godot）：https://bkhotey4.github.io/red-storm/

## 編譯與執行（Windows）

1. 安裝 Unreal Engine 5.4 與 Visual Studio 2022（C++ 遊戲開發工作負載）
2. 雙擊 `編譯_RedStorm_UE.bat`
3. 雙擊 `直接遊玩_RedStorm.bat`（第一次會自動建立地表材質）

詳細說明見 `README_紅色風暴UE.md`。

## 功能

日夜循環與天氣、掩體與高地、戰車輾壓、陣型移動（F）、戰損殘骸與瓦礫、網路作戰超級武器、外交、間諜、11 國、11 個任務。
